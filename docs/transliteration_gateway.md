# Transliteration-Based Access Gateway

## Purpose
Linguistic charter -> access control. No translation of authoritative text, transliteration only.

## Flow
Request -> Transliterate -> CharterLock (16 constraints) -> HITL -> Allow

## Compliance
- NO_CHARTER_WAIVER
- BIBLICAL_AUTHORITY_ABSOLUTE
- HITL_REQUIRED
- ZERO_TRUST_ISOLATION
